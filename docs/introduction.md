# 紹介文

## 概要

AIエージェントの設計・実装を示すポートフォリオとして、物流業務を題材にしたデモ「LogiScope」を制作しました。架空の業務データと文書を使い、ローカルLLMが検索ツールを選びながら調査し、回答と参照元を表示します。Reactの画面から質問するほか、デモ用の配送状況を報告し、再調査で変更を確認できます。

## 技術と設計の説明

Python／FastAPI、SQLAlchemy、PostgreSQL＋pgvector、React／TypeScriptを使用しています。業務データと文書を正本とし、検索用のチャンク・埋め込みは再生成できる構成にしました。エージェントのDB接続は読み取り専用とし、配送報告は別API・専用ロールで処理します。更新処理にはトランザクションとイベントキーを使い、同じ報告の再送に対応しています。

エージェントの処理には、引数の検証、重複呼び出しの検出、回数・時間の上限、例外処理を設けています。制御ロジックの自動テスト、実PostgreSQLを使う統合テスト、実ローカルLLMでのデモ確認を分けて実施しました。GitHub Actionsではリンタ・テスト・マイグレーション確認・フロントエンドビルドを実行しています。

架空データによるローカル環境のデモであり、本番運用を想定した認証や外部配送システムとの連携は実装していません。自動チェックだけでは回答の意味の正しさを保証できないため、デモの受入確認には正本との人による照合も含めています。
