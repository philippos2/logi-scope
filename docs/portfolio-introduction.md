# 応募用紹介文の下書き

## 短い紹介

LogiScopeは、物流会社の架空業務データと文書を横断調査するAIエージェントの公開デモです。ローカルLLMがToolを選択し、検索結果に応じて次の調査を進め、回答・根拠・操作履歴・未解決事項を返します。Reactの調査画面と、専用APIによる配送状況の報告・再調査も実装しています。

## 技術と設計の説明

Python／FastAPI、SQLAlchemy、PostgreSQL＋pgvector、React／TypeScriptを使用しています。業務DBと文書を正本、検索チャンクと埋め込みを再生成可能な派生データとして分離しました。AgentはDB権限でも読み取り専用とし、配送報告は別API・専用ロールで処理します。更新はトランザクションとイベントキーで整合性・冪等性を確保し、単一Tool内の読み取りは同じスナップショットへ揃えています。

Agent Loopには引数検証、限定的な修正、重複検出、回数・時間の上限、例外処理を実装しました。偽LLMによる制御テスト、実PostgreSQLの統合テスト、実ローカルLLMによる受入確認を分け、GitHub Actionsでリンタ・テスト・マイグレーション確認・フロントエンドビルドを実行しています。
