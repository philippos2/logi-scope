# 架空デモデータ

すべて架空の日本語データ。顧客30件、荷物90件、配送イベント177件、問い合わせ20件、文書13本を収録する。既存の5シナリオA〜EのID・内容は維持する。追加の顧客301〜310には各3荷物、401〜408には各3荷物、409〜416には各4荷物を関連付け、顧客内でも状態が異なる。

DBへ投入した後は業務テーブルが正本。文書は`seed/docs`が正本。問い合わせ・文書の検索チャンクはingestで再生成する。[更新手順](getting-started.md#db準備)を参照する。

## 追加の質問例と期待する事実

| 質問例 | DB・文書上の期待する事実 |
|---|---|
| 今、行方不明の荷物はありますか？ | missing登録はSHP-EXTRA-011・SHP-EXTRA-014・SHP-EXPAND-021・SHP-EXPAND-024の4件。所在調査中であり、紛失・盗難の確定ではない |
| 現在、どんな荷物が登録されていますか？ | 合計90件。配送中49件、遅延10件、配達完了27件、所在不明4件。総件数と取得した例の件数を区別する |
| 遅延中の荷物はある？ | 計10件。既存4件にSHP-EXPAND-003・006・009・012・015・018の6件を追加。missingと区別する |
| デモ風音食品の荷物が遅延している原因は？ | SHP-EXTRA-005、INC-EXTRA-001、強風による通行止め。配送再開・変更後の到着時刻は未確定 |
| SHP-EXTRA-008はどうして届かない？ | INC-EXTRA-002、建物名・部屋番号が不足。荷物の所在は確認済みで住所確認中 |
| SHP-EXTRA-011の所在は分かった？ | INC-EXTRA-003、積み替え後の現物確認ができず所在調査中。発見時刻は未確定 |
| デモ木陰書店の配達完了の荷物は？ | 顧客304、SHP-EXTRA-010。顧客と状態を組み合わせて検索する |
| デモ青空商店の行方不明の荷物はある？ | 顧客101のmissing登録はなし。遅延中のSHP-DEMO-001を所在不明扱いしない |

配送状態や時刻は架空の記録時点の情報であり、現実の現在の物流状況ではない。状態別検索でも取得上限があり、結果が省略された場合は取得件数を総件数と断定しない。総件数はToolが返した`total_count`、全体の状態別件数は`status_counts`、一覧の省略は`truncated`で確認する。

新しい質問の回答品質は、決定論的なTool・Agentテストと実LLMによる検証を分けて扱う。実測結果は履歴に記載する。

追加データの配分・実装範囲は[拡充仕様](demo-data-expansion.md)を参照する。

## 追加データの質問例

| 質問例 | 期待する事実 |
|---|---|
| デモ銀河資材の荷物を調べて | 顧客401・402の同名候補。営業所の指定が必要 |
| 架空第12営業所のデモ銀河資材の遅延荷物は？ | 顧客402、SHP-EXPAND-006の1件。他方の顧客401の荷物と混ぜない |
| SHP-EXPAND-003が遅延している原因は？ | INC-EXPAND-001、搬送台車の接触事故による安全確認。破損は未確定 |
| SHP-EXPAND-012が遅延している原因は？ | INC-EXPAND-002、橋梁点検の通行規制による迂回便調整。接触事故ではない |
| SHP-EXPAND-053の配送状態は？ | 配達完了、2026年10月4日10時00分（日本時間）。問い合わせはないが配送イベントで回答可能 |
| SHP-EXPAND-021の所在と発見予定は？ | 所在調査中。原因・発見予定は未確定で、紛失・盗難を断定しない |
| デモ冬虹工芸の行方不明の荷物はある？ | 顧客415にmissing登録なし |

同名顧客は既存のデモ双葉商会に加え、デモ銀河資材（401・402）、デモ霞色商会（403・404）を用意する。新規56荷物のうち8荷物に問い合わせを持たせ、残り48荷物には問い合わせを用意しない。事故・遅延報告書2本と一般的な遅延案内FAQ1本を追加した。一般的なFAQは個別荷物の原因や到着時刻を確定する根拠ではない。

## 追加ケースの検証範囲

上の期待事実は正本の内容を示し、任意の質問でAgentが必ず正しく調査できることを保証しない。実LLMの追加8ケースは、実行側の顧客ID検証・回答整合性確認・営業所検索の補正後に8件中8件成功した。別に言い換え8件も8件中8件成功。初期確認の失敗と修正も記録している。[検証履歴](history/demo-data-expansion.md)を参照する。
