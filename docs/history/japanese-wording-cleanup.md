# デモデータと質問例の日本語整理

2026年10月6日、PR #26をマージした最新main（`0fc5b81`）を取得し、データ・現在の案内文書・画面の質問例を整理した。

自然な口語は残し、不自然な語順や作成時の分類が見える名称を修正した。

- 「どんな荷物があるの今」を「現在、どんな荷物が登録されていますか？」へ変更。
- 「行方不明の荷物って今ある？」を「今、行方不明の荷物はありますか？」へ変更。
- 「架空追加第1〜10営業所」を「架空第1〜10営業所」、「架空拡充分第1〜16営業所」を「架空第11〜26営業所」へ変更。配送地区・集荷所も対応する番号へ統一。
- 所在不明報告の「倉庫への戻り」などの不自然な表現と、問い合わせ対応文の不要な空白を修正。
- 案内文書の「別窓」を「別のターミナル」とし、顧客の絞り込み条件は「営業所」に統一。

ID・件数・配送状態・日時・関連IDは維持した。過去の検証記録に引用された質問・名称は当時の記録として変更しない。口語への対応を確認する既存のAgentテストも維持した。

管理用seedを再適用し、変更した問い合わせ・文書から39チャンク・33正本の索引を再生成した。既存環境ではREADMEのseed・ingest手順を実行すると新しい文面が反映される。

自動テストはDB統合を含め221件中221件成功。フロントエンドは7件中7件成功。Ruff・ESLint・型確認・ビルド成功。

実LLMでは変更した質問例・営業所検索が3件中3件成功、既存A〜Eも5件中5件成功。公開応答は`artifacts/japanese-wording-verification.json`と`artifacts/demo-japanese-wording.json`に保持した。モデル・環境は既存のOllama `logiscope-qwen30-probe`（Qwen3 30B-A3B Instruct、8192コンテキスト）、WSL・RTX 3060 12GB。内部推論・生LLM応答全体は保存していない。
