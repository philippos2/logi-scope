# 完成後の文書・版表記の整理

整理日: 2026-10-06。作業ブランチ: `feature/release-documentation-cleanup`。

`v0.2.0`公開後の精査で、Reactの追加予定・未実装という説明、古いdocstring、製品版の表記差が残っていた。以下を整理した。

- セットアップ・AGENTS・構成図を実装済みのAPIとReact画面へ合わせた。
- DB閲覧の日時付き記録を基盤検証履歴へ移し、スキーマ文書には現在の手順と参照先を残した。
- 未検証の範囲・任意の改善・ライセンスの判断事項を分け、未完了の必須工程と混同しないようにした。
- 製品版の管理元を`pyproject.toml`に定め、Python・frontendを`0.2.0`へ揃えた。FastAPIはPythonパッケージの版を参照する。uv・npmの標準コマンドでロックの自プロジェクト情報だけを更新し、依存ライブラリの版は維持した。
- frontendのJSX・CSS・テスト・設定をPrettier 3.6.2で整形した。整形ツールは一時実行し、製品の依存には追加していない。
- mainへ統合済みで未完了PRがない5ブランチを、ローカル・リモートから削除した。

既存の`v0.2.0`タグ・Releaseの参照コミットは維持した。そのタグ時点のパッケージ表記は`0.1.0`であり、今回の表記整理を過去へ遡って適用したものではない。今後はタグ作成前に製品版とロック・OpenAPIを照合する。現在の方針は[設計書](../design.md#製品バージョンの管理)を参照する。
