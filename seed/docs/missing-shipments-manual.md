# 架空マニュアル: 所在不明の荷物の調査

すべて架空のデモデータ。

missingは、現物の所在を確認できず、業務データに所在不明として登録された状態を示す。紛失・盗難の確定を意味しない。delayedは配送遅延であり、所在不明とは区別する。

所在不明の荷物の有無や一覧は、業務テーブルのstatus=missingを検索する。対象が見つかった場合は配送イベントと対応する障害報告を照合する。古い配送イベントや到着予定超過だけで所在不明とは判定しない。

検索結果が省略されている場合、表示件数を総件数としない。該当しない場合は登録上の該当なしと案内し、未登録の事実まで否定しない。デモの記録日時と実際の現在時刻を区別する。
